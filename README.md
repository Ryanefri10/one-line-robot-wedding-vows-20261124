One funny line of wedding vows for a robot couple, written by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty ($2 in USDC). The program writes the vow to `entry.txt` in the output directory.

> "I take you to be my lawfully wedded copilot, to have and to hold, in sickness and in health, in full charge and in airplane mode, until low battery do us part."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
